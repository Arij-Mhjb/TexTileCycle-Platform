# Galerie de la version déployée

**39 captures réelles — 8 octobre 2026** sur [TexTileCycle](https://textilecycle.onrender.com/) : 5 publiques, 14 administrateur, 9 marque et 11 consommateur. Fichiers JPEG du navigateur, sans montage ni données ajoutées.

Les trois comptes de démonstration ont été ouverts avec autorisation. Aucun formulaire métier n’a été soumis pour les captures. Aucun ticket, justificatif privé, mot de passe ou code de dépôt n’est inclus. Le SHA exécuté par Render n’est pas confirmé ; ces vues ne constituent pas un test complet des intégrations.

Les inscriptions marques, les collecteurs et les feuilles de route présentent leur état vide réel. L’orientation produit-label indique une analyse déterministe. Les images de remplacement du catalogue restent telles qu’affichées.
